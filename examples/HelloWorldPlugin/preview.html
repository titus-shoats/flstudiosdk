🚀 Key Features

  • Native FL Studio Plugin: Uses FL Studio SDK, not VST/AU
  • JUCE GUI: Beautiful gradient background with custom text rendering
  • Minimal Example: Clean, educational code structure
  • CMake Build: Modern build system with automatic JUCE download
  • Well Documented: Comprehensive README and architecture docs

🔨 Build Instructions

cd examples/HelloWorldPlugin
mkdir build && cd build
cmake .. -G "Visual Studio 16 2019" -A x64
cmake --build . --config Release

The built DLL should be placed in:
<FL Studio>/Plugins/Fruity/Generators/HelloWorld/HelloWorld.dll

  • Advanced GUI: Add interactive controls, visualizers, etc.
